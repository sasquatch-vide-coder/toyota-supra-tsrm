Engine Mechanical — Description
DESCRIPTION

The 2JZ engine series uses a cast iron block with an aluminum cylinder head. The 2JZ-GE is a naturally aspirated 3.0 liter inline 6-cylinder engine, and the 2JZ-GTE is its turbocharged variant.

ENGINE SPECIFICATIONS
Engine Type 2JZ-GE / 2JZ-GTE
Displacement 2,997 cc (3.0L)
Bore x Stroke 86.0 x 86.0 mm
Compression Ratio 10.0:1 (GE) / 8.5:1 (GTE)
Horsepower (GE) 220 hp @ 5,800 rpm
Horsepower (GTE) 320 hp @ 5,600 rpm
Torque (GE) 210 lb-ft @ 4,800 rpm
Torque (GTE) 315 lb-ft @ 4,000 rpm
CYLINDER HEAD

The cylinder head is made of aluminum alloy with pentroof-type combustion chambers. It uses dual overhead camshafts (DOHC) with 4 valves per cylinder (24 valves total).
